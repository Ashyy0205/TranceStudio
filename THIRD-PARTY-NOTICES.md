## FFmpeg

Trance Studio ships an unmodified FFmpeg program (ffmpeg.exe on Windows, ffmpeg on Linux) and runs it as a
separate process. FFmpeg is licensed under the GNU General Public License version 3. The builds come from the
ffmpeg-static project (https://github.com/eugeneware/ffmpeg-static): Windows builds by Gyan Doshi
(https://www.gyan.dev/ffmpeg/builds/) and Linux builds by John Van Sickle (https://johnvansickle.com/ffmpeg/).
The FFmpeg source code is available from https://ffmpeg.org/download.html and
https://github.com/FFmpeg/FFmpeg; the Windows build used is from commit e38092ef93. The full GPL text is
installed next to the program as ffmpeg.exe.LICENSE (Windows) or ffmpeg.LICENSE (Linux), and is also at
https://www.gnu.org/licenses/gpl-3.0.txt.
