# Keyboard shortcuts

## Everywhere

- F1 opens this manual at the topic for what you have selected.
- Ctrl+1 shows the Media page and Ctrl+2 the Edit page.
- Ctrl+S saves, Ctrl+Shift+S saves as a new file, and Ctrl+O opens a session.
- Ctrl+Z undoes, and Ctrl+Y or Ctrl+Shift+Z redoes.
- Ctrl+E opens the export window.
- F5 watches fullscreen, and Esc leaves fullscreen.

## Edit page

- Space plays and pauses.
- Home jumps to the start and End to the end.
- Delete removes the selected block or clip.
- Ctrl+scroll zooms the timeline.
- Shift while resizing a look block uses 1 second steps.
- Alt while dragging turns off snapping.

## Media page

- Click selects, Ctrl-click and Shift-click select more, and Ctrl+A selects everything shown.
- Enter adds the selection to the highlighted theme.
- Delete removes the selected items from the highlighted theme. Your files are not deleted.
- Esc clears the selection.
- Double-click shows an item full size. In that view, the arrow keys move through the folder, Space
  selects and Esc closes.
